# Grind

Grind is an Android productivity app designed to help people break the habit of doomscrolling, reduce wasted time, and build better daily focus. It monitors app usage, limits time spent on distracting apps, and enforces focus sessions so users can complete their real priorities before they unlock their phone.

This app is built for people who want to be more intentional with their time, especially in a world where social media and endless notifications often compete with productivity.

## Why Grind?

Many people start the day by checking messages, social media, or short-form content before finishing the most important work. Grind flips that pattern by making focus the default.

Instead of casually using your phone all day, Grind helps you:

- Track app usage and screen time
- Set app-specific time limits
- Lock distracting apps when limits are reached
- Force task-first behavior before access is restored
- Build stronger daily routines around focus and discipline

## Key Features

- App time tracking
- Daily usage limits
- App locking enforcement
- Task-first productivity flow
- Focus-oriented Android workflow
- Built for people who want to reduce distraction and build better habits

### Installation Notes

1. Download the APK to your Android device.
2. If Android blocks installation, enable Install unknown apps for your browser or file manager.
3. Open the APK and follow the installation prompts.
4. Grant the required permissions to allow the app to monitor usage and enforce app locks.

## Permissions and Why They Are Needed

Grind may request permissions such as:

- Usage Access: to monitor which apps are being used and for how long
- Accessibility: to detect app launches and restrict access when limits are reached
- Device Admin / Locking privileges: to help enforce protection and prevent casual bypass while the app lock is active

These permissions are required for the app to function as intended. Please review them carefully before installing and using the app.

## Important Warning

This app is designed to restrict access to apps and certain device functions while protection is active. That means it can block or limit behavior that is normally available in Android. This is intentional for productivity discipline, but it is important to understand the consequences before enabling the lock.

If you are using the app to enforce strict focus, make sure you are comfortable with the access level it requires.

## Uninstall / Recovery

Because Grind can request admin-level access, uninstalling it may require additional steps if the lock is active. If you ever need to remove it:

- Deactivate the app's device admin / administrator privileges in your Android settings
- Then uninstall it from the app list
- If settings are blocked, try rebooting into Safe Mode or use Android tools such as ADB if you are familiar with developer options
